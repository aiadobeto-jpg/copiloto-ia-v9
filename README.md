# Co-piloto.ia — Florianópolis

Painel premium para motorista de aplicativo, consolidando a experiência Runable com o Motor Cognitivo V9.

## O que está integrado

- Interface premium Runable com check-up automático, ranking de bairros, localização, clima, feriados e eventos.
- Módulo **Inteligência V9** no mesmo aplicativo, acessível pelo botão flutuante.
- Previsão de 6 horas, regras do dia, zonas mortas, relações entre bairros e ranking de melhor bairro.
- Analisador de corrida, analisador turbo, controle de turno, custos, ociosidade, histórico e exportação.
- Conselheiro, alertas de segurança, botão de pânico, voz, clima Open-Meteo e persistência local.
- Sem backend obrigatório: os dados locais ficam no dispositivo.

## Uso

Abra `index.html` no navegador. Para usar GPS e clima real, permita localização e conexão quando solicitado.
